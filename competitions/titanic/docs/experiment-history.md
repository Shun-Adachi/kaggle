## 経緯と判断

### 1. ベースライン(3モデル比較)

王道構成(Pipeline+ColumnTransformer、StratifiedKFold 5-fold seed42)で
logreg / RandomForest / LightGBM を比較。891件の小データでは線形モデルが最良だった。
初回提出で CV 0.8283 → LB 0.76794 の乖離(▲0.06)を確認し、
「CV と LB の差ではなく連動を見る」方針を立てた。

### 2. 誤答分析ドリブンの特徴量改善

OOF 予測(cross-validation の各検証フォールドを繋いだ 891人分の予測)で誤答を
セグメント別に分析する手法を導入(`notebooks/error_analysis.py`)。
難所は female C3(誤答28.5%)と male C1(35.2%)に集中していると判明。

- Title 別 Age 補完: 年齢不明の Master(男児)が全体中央値28歳で大人扱いされる問題を修正
- Ticket グループ特徴: 同一チケット=同行グループ。FamilySize が見落とす友人・使用人を捕捉
- Cabin・ビン化は全体 CV で効果なし → 不採用

### 3. グループ運命連動特徴(WCG)— 最大の改善

「同行者に生存者がいる女性の生存率 98.1% vs 同行者全滅の女性 37.5%」という
運命の連動を特徴量化(GroupSurvRate)。正解ラベル由来のためリーク対策が必須:
CV の各フォールドで学習側ラベルのみ使用、本人は leave-one-out で除外。
本家 Woman-Child Group の知見どおり、集計対象を女性・子供に限定(wcg2)すると更に改善。
LightGBM のチューニングは「浅く・遅く・少なく」(lr 0.03 × 100本 × 葉15)が正解。

### 4. LB の壁と診断(転機)

CV 0.8608 の構成を提出しても LB 0.76794 でベースラインと同一。診断の結果:

- **グループ特徴は test では 20.3%(85人)にしか発火しない**。train 内で完結する家族が
  多く、CV での改善の大半は test に持ち出せない種類のものだった
- グリッド探索(累計162通り)を単一 seed の CV で選んだことによる選択バイアス

### 5. 検証の正直化(repeated CV)

CV 分割 seed 0〜9 の10通りで再評価(`src/repeated_cv.py`)。判明したこと:

- seed 42 は LightGBM 系に一貫して甘い分割(+0.013〜0.019)
- wcg / wcg2 / wcg3 は統計的に同格。「本家方式で改善」はほぼ分割運だった
- 正直な現在地は CV 0.842 ± 0.006

**以後の実験ルール: 採否判定は repeated CV 平均で行い、2σ(≒0.012)未満の差は同格とみなす。**

### 6. ルールハイブリッドの検証 → 不要と判明

「グループ証拠が強い場合に後処理で上書きする」定石手法を検討したが、実測の結果
**チューニング済みモデルは既に証拠へ完全追従していた**(WCグループ全滅の女性34人
全員を確率0.05前後で死亡予測。test でも上書き対象0件)。後処理層は撤回。
ルールハイブリッドが効くのは WCG 特徴を持たないモデルに対してのみ。

### 7. 残りの手の検証(セグメント別評価器)

セグメント別 OOF 正解率 × repeated CV の評価器(`src/segment_cv.py`)を作成し、
残っていた2案を判定:

- 姓ベースの拡張グループ(別チケットの家族を union-find で連結): test カバレッジ
  85→88人(+3人)で効果極小。「家族なのに別チケット」はほぼ存在しなかった
- cabin の male C1 局所再評価: +0.1% で効かず。単変量で差があっても(デッキ記録なし21%
  vs E deck 53%)、既存特徴(Fare 等)と重複していれば予測力は増えない

最終提出(wcg2sc)は repeated CV では基準と同格ながら LB 0.77751 で自己ベスト。
CV の分解能以下の差は事前に判別できないことも含めて確認となった。

### 8. 立ち位置の可視化とアンサンブルの顛末(2026-08-03)

公開LB全体(11,194チーム)を取得して分布内の位置を測定(`notebooks/lb_position.py`):
自己ベスト 0.77751 は上位29.9%、中央値 0.77511、1人正解=+0.239%。0.85超は暗記勢のみで
実力上限は 0.80〜0.83。test 側の残り誤答の所在も推定(`notebooks/test_gap_analysis.py`):
期待誤答66人 vs LB実測93人で、乖離27人分の主因は WCG 証拠が test の21%にしか
届かないことと特定。

アンサンブルを**ペア比較 repeated CV**(同一 seed 同士の差の符号検定)で再判定したところ、
avg3(logreg+rf+lgbm_t の確率平均)が 10 seed 全勝(+0.0054)で「本物の改善」と確認。
過去の「アンサンブル不採用」は seed42 の分割運による誤判定だった。

しかし提出すると **LB 0.75358(2勝12敗、-10人)で棄却**。差分14人の大半が
male C1 を「生存」に倒す賭け(事前確率 ~1/3)で、CV の改善は誤答分析で
「運の層」と特定済みの FN 層に乗っていた。train 分布上の統計的に本物の改善でも、
運の層に乗った改善は test に持ち出せないことを実測で確認。

→ 実験ルールに昇格: **提出前に現ベストとの diff を取り、予測が変わる乗客の層を確認する。
運の層の入れ替えなら CV 改善は持ち出せない。**

### 9. CV-LB 乖離の解剖と test 特徴量バグの発見(2026-08-03)

「CV と LB のデータの性質の差」を直接測定(`notebooks/train_test_shift.py`):

- adversarial validation AUC 0.500、KS/カイ二乗もほぼ n.s. — **属性分布に差はない**
- WCG 証拠カバレッジの真値は train 29.2% vs test 26.8% とほぼ同等。
  過去の「test は 20.3% しか発火しない」という診断は、`add_group_feature` の
  LOO 判定が index ベースだったバグ(train と test の index 衝突で test 24人が証拠喪失、
  37人の rate 汚染)による誤測定だった。PassengerId 判定に修正済み。
  CV は fold 間で index が一意なため無影響。修正後の test 予測は1人も変わらず、
  過去の提出は結果的に無傷。
- ただし **female C3 だけは証拠カバレッジが train 42% → test 28% に落ちる**。

難所層の正解行/不正解行の4群比較(`notebooks/hard_segment_eda.py`、TP/FN/TN/FP)で
精度上限の実体を可視化:

- **正誤を分けるのは属性ではなく WCG 証拠の有無**。female C3 の FP 25人は全員証拠なしで
  当てた行と属性同一。male C3 で当たる生存者は「証拠つきの子供」だけ。
  male C1 は Age 以外に軸がなく、生存に賭けたときの的中率 62% が構造的上限。
- CV-LB 乖離の残りは、選択バイアス(LB を見て構成を選んだ分)と
  「属性同一・生死不定」層の test での実現値(引き)で説明される。

### 10. 残り仮説の全数検証とクローズ(2026-08-03)

最後に、残っていた改善仮説を正直な検証(ペア比較 repeated CV + diff 層チェック)で
一つずつ白黒つけた:

- **male C1 深掘り**: 「大人の男性に WCG 証拠は効かない」構造は実在(rate=1 でも
  生存 27.7%、全滅なら 20/20 死亡)。証拠マスクは male C1 +1.1人だが female C3 で返上
  (共有木の副作用)。IsWC フラグ(wcg2scw)は CV +2.2人(7勝2敗)だが
  **LB 0.77272(2勝4敗)で棄却** — 判定バー未達の構成は提出しない、をルール化。
- **年齢の全数検証**: 補完 MAE は 9.4→8.6 歳まで改善可能(Title×Pclass・回帰)だが
  survival は不動(補完値が動いても予測帯は変わらない)。誤答129人中 Age 欠損は19人のみで、
  欠損者の誤答率(10.7%)は既知者(15.4%)より低い。「生死が明確な年齢帯」
  (male 0-12×上級 100%、male 50+×下級 4.3% 等)は実在するが全てモデル追跡済み。
  「年齢不明者を明確帯に補完して予測を動かす」案は、敬称(Master)と Parch が子供を
  ほぼ完全に開示しているため適用対象が 0〜1人しか存在しない。
- **ルールマイニング**: 条件2〜3個の組み合わせで「生死ほぼ確定セル」98件を発見。
  ただし fold 内で正直に発掘して検証側を上書きすると **-0.4人** —
  モデルは全ての法則を吸収済み。全データで見える「+5〜8人の余地」は選択バイアス。
- **未使用軸**: 客室番号の奇偶(左右舷)は差なし、運賃0円(15人)は既に死亡予測、
  チケット接頭辞は Pclass×港の代理で paired CV -0.6人。

**最終結果: Public LB 0.77751(lgbm_t/wcg2sc)= 11,194チーム中 上位29.9% で確定。**
残誤答約90人は「法則の取りこぼし」ではなく「法則が存在しない領域」であることを
実測で確認してクローズ。

## 精度の天井について

- 難所セグメントの理論上限を「同一情報セル内の生死混在」で測定: male C1 は 69〜84%
  (真値はおそらく75%前後、現状70.5%)。Baxter氏/Bishop氏(ほぼ同一属性で生死が逆)の
  ような「データに写っていない要因」(当日の居場所・ボート列)が残誤答の主因
- 誤答の中心は「属性上は死亡が濃厚なのに生き残った男性」の FN で、特徴量では削れない
- 実力ベースの現実的な到達点: CV 0.84 前後、LB 0.78〜0.80(LB 上位の 1.0 は史実の
  答え合わせであり参考にならない)

## 教訓(次コンペへの持ち帰り)

1. **単一 seed の CV でグリッド選択すると系統的に上振れする。** 早期に repeated CV を
   導入し、σ を測ってから改善を判定する
2. **CV 改善と LB 改善は別物。** 特徴がテストデータで「発火するか」(カバレッジ)を
   提出前に必ず確認する
3. **誤答分析(OOF × セグメント)は投資対効果が高い。** どこを直すべきか・直せないかが
   数字で分かり、死に筋(ルールハイブリッド、cabin)を実測で棄却できた
4. **単変量の差 ≠ モデルへの寄与。** 既存特徴と重複する情報は足しても効かない
5. **理論上限(同一情報セルの混在率)を測ると「あと何点取れるか」の期待値管理ができる**
6. ラベル由来の特徴(グループ生存率)は強力だが、リーク対策(フォールド内計算+LOO)と
   「評価と本番で同じパイプライン」の原則を崩さないこと
